Bounds file

pfsp-bounds.csv has one row per instance:

instance
name (ta001…ta120, VRF10_5_1…)
set
taillard, vrf-small, vrf-large
n, m
jobs, machines
LB, UB
best-known lower / upper bound (LB empty if none is recorded)
gap_percent
100·(UB−LB)/UB
status
closed (LB = UB) or open
LB_ref, UB_ref
reference keys, resolved in references.bib
updated
date of the last change (ISO 8601)

pfsp-solutions.csv holds instance, makespan, ref, permutation, with job indices from 1.

VRF instance names follow the upstream files (VRFn_m_k). The benchmark itself is usually called VRF after its authors.
