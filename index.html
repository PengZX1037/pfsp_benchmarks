How to cite

If you use these bounds, please cite this repository and the papers that established them. Each instance page lists those papers, and references.bib collects them all.

Found a better solution?

Email it to . New upper bounds are accepted only with their permutation, which is re-evaluated automatically. New lower bounds need a citable document describing the method.
